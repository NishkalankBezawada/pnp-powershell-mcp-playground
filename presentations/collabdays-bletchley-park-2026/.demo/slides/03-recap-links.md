# Recap

1. **One local server, any MCP client** — VS Code, Visual Studio, Cursor, Claude Code
2. **It doesn't own your credentials** — it reuses your PnP connection
3. **Discovery before execution** — the agent looks the cmdlet up instead of guessing
4. **Destructive work stays gated** — you approve, every time
5. **The best answer is sometimes "you can't"** — cascading lookups are still form-layer work
