# Speaker Notes: Title

## What to say

Keep the opening short. Something like:

> "For the next ten minutes I'm going to talk to a real Microsoft 365 tenant in plain
> English, and PnP PowerShell will do the actual work."

It's worth mentioning that this is a live tenant rather than a recording. People tend
to pay more attention once they know that, and it's only fair to tell them.

## The short version of what this is

MCP, the Model Context Protocol, is how an AI client finds and calls tools. The PnP
PowerShell MCP Server is a local server that exposes PnP PowerShell as those tools. It
runs on your own machine, under your own account, using a connection you made yourself.

That's enough for now. The next slide covers the detail.

## Things to leave out here

No need to list the tools yet, and no need to explain MCP properly. If people don't
know what MCP is, the demo will teach them faster than an explanation would.

About 20 seconds.
